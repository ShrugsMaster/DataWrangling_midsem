SELECT c.city, SUM(o.amount) AS total_order_amount          
FROM customers c
JOIN orders o ON c.customer_id = o.customer_id
GROUP BY c.city
HAVING SUM(o.amount) > 1000
ORDER BY total_order_amount DESC;

output -
Delhi with total amount as 3650
Mumbai with total amount as 3650

mistake was in connecting the tasks: extract() returns the list,
so you need to store it in a variable and pass that variable to total(numbers) instead of writing extract >> total().
 Also, task.python should be @task, and the DAG needs to be called at the end with report_dag()
 corrected one -
 
from airflow.sdk import dag, task
@dag(dag_id="daily report", schedule=None)
def report_dag():

    @task
    def extract():
        return [1, 2, 3]

    @task
    def total(numbers):
        print(sum(numbers))

    numbers = extract()
    total(numbers)

report_dag()
